# SDLC AI — AI Maturity Framework

Projects reaching Level 2 or Level 3 of AI Maturity must have all relevant dimensions fully addressed. Upon reaching L2 or L3, a validation process ensures consistent and exemplary expertise across all AI Maturity dimensions.

## AI Maturity Levels

| Dimension | L1: Inconsistent & Ad-hoc | L2: Systematic & Scalable | L3: Disruptive & Novel |
|-----------|--------------------------|--------------------------|------------------------|
| **AI Capabilities** | Assisted: deliverables created with AI, results vary | Augmented: >50% of core role deliverables created/verified with AI | Agentic: novel features, agents handle sub-tasks, new ways of working |
| **Reusability** | Siloed: local prompts/scripts per individual | Shared: onboarding materials, prompts, rules, context shared | Codified: rules, custom agents maintained as code, automated |
| **AI Champions** | Sporadic: enthusiasts without coordination | Designated: at least one AI champion assigned | Embedded: all core roles involved |
| **Performance Tracking** | Partial: anecdotal evidence, no standardized metrics | Tracked: productivity metrics defined and consistently measured | Governed: AI cost tracking, regular optimization reviews |
| **Daily Active Users** | Low: occasional use | Majority: >70% DAU | Prevalent: >80% DAU |
| **Level Score Range** | 1.0 – 1.9 | 2.0 – 2.9 | 3.0 |
| **Validation** | Not required | Required | Required |

## Commodity vs Novel

**Commodity / Standard:**
- Mass adoption, released by major vendors (Microsoft, Google, Amazon)
- Well-known industry features (code completion, chat, simple agents, code review, MCP integration)
- Ways of working portable across toolsets

**Novel / Experimental:**
- Features present in only a few tools
- Spec-driven development, lengthy batch processing of source code
- Custom agentic solutions using orchestration (LangChain, etc.)
- Multi-agent flows (A2A/ACP protocols)
- Programmatically built AI agents embedded into SDLC

## AI Maturity — Location Level

**L0 Traditional / At High Risk** — no AI integration, no AI Champions, no AI skills considered in hiring.

**L1 Inconsistent & Ad-hoc / At Risk** — informal AI activities, shadow enthusiasts, sporadic junior exposure, no formal recognition.

**L2 Systematic & Scalable Baseline** — every L2+ project has a tracked AI Champion, systematic junior onboarding as AI-native, AI fluency mandatory for senior hires, regular hackathons and learning marathons.

**L3 Disruptive & Novel Frontier** — location as AI innovation hub, all key roles filled by networked AI Champions, majority of talent in advanced AI projects, all juniors AI-native, external community representation.

## Validation Dimensions

- **AI Capabilities** — % of deliverables created/assisted by AI; evidence via screenshots from tools (Jira tags, code repos). Novel tools usage required at L3.
- **Reusability** — screenshots from shared sources (Confluence, SharePoint, GitHub/Bitbucket). Source control screenshots mandatory if L3 claims SDLC agents.
- **AI Champions** — name, count, activities.
- **Performance Tracking** — screenshots from Jira, Azure DevOps, or survey tools. Metrics must be clearly visible.
- **Daily Active Usage (DAU)** — telemetry screenshots or surveys. Tools: Cursor dashboard, GitHub Copilot admin, CodeMie Analytics, EliteA monitoring.
- **Novel Tools** — required for L3 only.
- **AI Costs** — required for L3; screenshots from cost analytics tools with optimization explanations.
