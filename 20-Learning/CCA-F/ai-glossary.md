# AI Glossary — CCA Reference

Quick-reference definitions for AI/ML terminology relevant to the CCA exam.

| Concept | Definition | Examples |
|---|---|---|
| Artificial Intelligence (AI) | Broad field of building systems that perform tasks requiring human intelligence: reasoning, perception, decision-making | Chatbots, recommendation systems, autonomous vehicles, fraud detection |
| Machine Learning (ML) | Subset of AI where systems learn patterns from data and improve without being explicitly programmed for every rule | Spam filtering, product recommendations, demand forecasting, credit scoring |
| Deep Learning (DL) | Subset of ML using layered neural networks to learn complex patterns from large datasets | Image recognition, speech recognition, language translation |
| Natural Language Processing (NLP) | AI subfield enabling computers to understand, interpret, generate, and work with human language | Chatbots, translation, voice assistants, sentiment analysis |
| Natural Language Understanding (NLU) | NLP component focused on extracting meaning, intent, entities, and context from language | Intent detection in chatbots, entity extraction from documents |
| Natural Language Generation (NLG) | NLP component focused on producing human-readable text from data or machine outputs | Automated reports, response generation, summarization |
| Neural Network | Computing model inspired by the brain, made of connected layers that learn patterns from data | Image classification, speech processing, text modeling |
| Training Data | Data used to teach a model to recognize patterns or make predictions | Historical sales data, labeled spam emails |
| Labeled Data | Data where each example includes the correct answer or category; used in supervised learning | Emails marked "spam/not spam", photos labeled by object type |
| Unlabeled Data | Data without predefined labels; used in unsupervised learning or pretraining | Customer behavior logs, raw text corpora, sensor data |
| Supervised Learning | ML approach learning from labeled examples to predict outcomes | Classification, regression, sentiment analysis, house price prediction |
| Unsupervised Learning | ML approach finding hidden patterns in unlabeled data | Customer segmentation, topic modeling, anomaly detection |
| Reinforcement Learning | Learning by trial and error; agent takes actions and receives rewards or penalties | Game playing, robotics, dynamic pricing, resource optimization |
| Classification | Prediction task assigning an input to one of several categories | Spam detection, image labeling, sentiment analysis |
| Regression | Prediction task estimating a continuous numeric value | Sales forecasting, price prediction, temperature estimation |
| Feature | A measurable input variable used by a model to make predictions | Age, income, word frequency, click count |
| Feature Engineering | Creating or transforming input variables so a model can learn better | Building text embeddings, normalizing values, time-based features |
| Model | A mathematical representation learned from data that maps inputs to outputs | Fraud detection model, translation model, recommendation model |
| Algorithm | A procedure used to solve a problem or train a model | Decision tree, logistic regression, neural network training |
| Overfitting | Model learns training data too closely; performs poorly on new data | Model that memorizes past emails but fails on new spam |
| Underfitting | Model too simple to capture important patterns | Weak forecast model that misses clear sales trends |
| Generalization | Ability to perform well on new, unseen data | Churn model that works reliably on future customers |
| Hyperparameter | Configuration chosen before training that influences how a model learns | Learning rate, number of layers, tree depth |
| Accuracy | Proportion of correct predictions | How many spam predictions were correct |
| Precision | Proportion of predicted positives that are truly positive | Of flagged emails, how many were actually spam |
| Recall | Proportion of actual positives the model correctly finds | Of all fraud cases, how many were caught |
| F1 Score | Single metric balancing precision and recall | Comparing classifiers for imbalanced datasets |
| Prompt | Input text given to an AI system to guide its output | Asking a chatbot to draft an email or classify intent |
| Large Language Model (LLM) | Large neural model trained on vast text data to understand and generate language | Chatbots, writing assistants, search copilots, document summarization |
| Token | Small unit of text used by LLMs — word, part of a word, or symbol | Breaking a sentence into pieces before processing |
| Embedding | Numeric representation of text, images, or data capturing meaning or similarity | Semantic search, recommendation systems, document clustering |
| Transformer | Neural architecture handling context well in language tasks; underpins modern NLP | Translation, summarization, question answering, LLMs |
| Sentiment Analysis | NLP technique identifying emotional tone in text | Social media monitoring, product review analysis |
| Named Entity Recognition (NER) | NLP identifying names of people, organizations, locations, dates, etc. | Extracting company names from contracts, dates from emails |
| Text Classification | NLP assigning text to a category | Spam detection, topic tagging, intent classification |
| Text Summarization | NLP creating a shorter version while preserving main points | News summaries, meeting notes, research abstracts |
